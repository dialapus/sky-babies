# Небесные малыши

Браузерный 3D-раннер: малышка убегает от небесного почтальона по трём облачным дорожкам, собирает крылатые подарки и ненадолго учится летать. Язык интерфейса — русский. Без сборки, аккаунтов и внешних сетевых запросов во время игры.

## Запуск

Распакуйте игру и раздавайте **всю папку** любым статическим HTTP-сервером. Например, из корня игры:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080/`. На Windows команда Python может называться `py -m http.server 8080 --bind 127.0.0.1`.

Двойной щелчок по index.html (`file://`) не подходит: браузер ограничивает ES-модули. Нужен современный браузер с WebGL. Локальная three.js 0.160.1 находится в `vendor/three/three.module.js`; npm для игры не нужен.

## GitHub Pages и подпапка

Положите содержимое архива в обслуживаемую папку сайта. Вариант `/sky-babies-run/` поддерживается: CSS, модули, значки и importmap используют относительные пути, нет ссылок от корня `/`. Браузерные проверки запускают сайт именно под `/sky-babies-run/`.

Для публикации нужны `index.html`, `css/`, `js/`, `assets/`, `vendor/` и `.nojekyll`. Папка `tests/`, отчёты и package.json не нужны для игры. Эта поставка ничего не публикует и не меняет настройки GitHub.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Дорожка влево / вправо | ← / → или A / D | Свайп влево / вправо |
| Прыжок | ↑, W или пробел | Свайп вверх |
| Подкат | ↓ или S | Свайп вниз |
| Пауза / продолжение | Esc или P, кнопка паузы | Кнопка паузы |

Свайпы выполняются по игровому полю, а на сенсорных экранах дополнительно доступны четыре экранные кнопки. Минимальная длина свайпа — 28 CSS-пикселей. Во время прыжка свайп вниз ускоряет приземление и включает подкат; двойного прыжка нет. При потере фокуса или сворачивании вкладки забег ставится на паузу и ждёт явного продолжения.

## Правила

**Стеклянная почтовая труба:** перепрыгните либо смените дорожку. **Арка из подарков:** проскользните под ней или обойдите; прыжок в арку не помогает. **Дыра:** настоящий разрыв облачного полотна длиной 8 метров. Перепрыгните или выберите соседнюю дорожку. Приземление в разрыв запускает падение и экран «Чуть не упала на Землю!».

Первое столкновение с трубой или аркой вызывает спотыкание и приближает небесного почтальона; второе скорое столкновение может завершить забег. При чистом беге почтальон постепенно отстаёт. Есть краткая защита от повторной обработки одного столкновения.

Подарки с крылышками увеличивают счёт и валюту нарядов. Отдельная пара **«Крылышки»** даёт 9 секунд полёта над всеми препятствиями. Следите за полоской времени: после окончания бонуса героиня опускается обратно на дорогу.

Скорость растёт с 12 до 25 м/с. Между рядами препятствий 24 м; в каждом ряду минимум одна дорожка полностью свободна. Примерно первые 30 секунд на каждом ряду одно препятствие; маршрут меняется постепенно, без обязательного перехода сразу через две дорожки. Перед падением в дыру есть небольшое окно последнего прыжка, а накануне приземления — буфер нажатия. Почтальон отступает при чистом беге, его видимая позиция зависит от danger.

Счёт: `floor(метры × 10) + подарки × 50`. Рекорд, пять лучших забегов, накопленные подарки, звук, качество и выбранный наряд сохраняются в localStorage под ключом `sky-babies-run.v1`. Подарки зачисляются после поражения либо при «Завершить и в меню» на паузе; незавершённый забег при закрытии вкладки не зачисляется.

## Наряды и настройки

Базовый розовый комбинезон и три расцветки за **300 / 500 / 1000** подарков. Купленный наряд можно надевать повторно бесплатно. Это только визуальные изменения; платежей и рекламы нет.

Звук — синтезированные короткие мелодические сигналы WebAudio без загрузок. AudioContext создаётся только после взаимодействия, автотесты стартуют без звука. Качество: **Авто**, **Высокое**, **Низкое**. На мобильных устройствах DPR ограничен 1,5; на desktop высокий режим ограничен 1,75. В автоматическом режиме DPR динамически снижается до 0,67 при медленных кадрах; на программном рендере начальное разрешение дополнительно снижено для плавности. Высокое качество можно выбрать вручную, пожертвовав FPS. Тени и постобработка отключены; дорожки/подарки/частицы инстансированы, статические части персонажей объединены по материалам.

## Автотесты в адресной строке

- `?autotest=fall`: автозапуск по центральной дорожке в заранее поставленную дыру. Управление отключено, сначала видна анимация падения, затем поражение; при нормальной частоте кадров это около 4–5 секунд. На программном WebGL может быть медленнее.
- `?autotest=run`: автозапуск бесконечного бега **с защитой от поражения**. Управление доступно. Это режим осмотра рендера и интерфейса, а не доказательство безопасности обычных столкновений.

Автотесты не записывают рекорды и подарки. Для обычной игры уберите параметр. `window.__SKY_BABIES__.snapshot()` возвращает только диагностический снимок: состояние, счёт, физику, DPR, геометрию и частоту кадров. Изменять игровое состояние через него нельзя.

## Проверки разработчика

Чистая симуляция, ресурсы, хранение, подкаталог /sky-babies-run/ и COOP/COEP проверяются через Node.js 22:

```sh
npm test
# эквивалентно: node --test tests/
```

В этой поставке **38 тестов**, включены проверки детерминизма, прыжка у края, буфера ввода, «run» и «fall». Быстрый прогон в Chrome через DevSpace preview использует также автономные страницы `acceptance-run.html` и `acceptance-fall.html`. Отдельный Playwright-скрипт `tests/browser.mjs` остаётся опциональным: требует предварительной установки Playwright и Chromium и не запускался на сервере из-за отсутствующей зависимости.

Браузерная проверка и PNG точного размера (не требуется для самой игры):

```sh
npm install --prefix tests/headless --cache tests/.npm-cache --ignore-scripts --no-audit --no-fund playwright@1.51.1
PLAYWRIGHT_BROWSERS_PATH=0 node tests/headless/node_modules/playwright/cli.js install chromium --only-shell
PLAYWRIGHT_BROWSERS_PATH=0 node tests/browser.mjs
```

Команды для POSIX shell. На Windows задайте `PLAYWRIGHT_BROWSERS_PATH=0` способом Вашей оболочки. Скрипт сам создаёт временный HTTP-сервер на `127.0.0.1`, блокирует внешние запросы, проверяет интерфейс и управление и закрывает сервер. Результаты — `tests/browser-results.json`, снимки — `tests/screenshots/`. Playwright, Chromium и кэши не входят в архив игры.

## Ограничения

Процедурная low-poly интерпретация утверждённых изображений, не фотореалистичная копия концепт-артов. Референсы не используются как плоская подмена 3D и не нужны для запуска. Нет сервера рекордов и синхронизации устройств. Очистка данных браузера удаляет прогресс; при запрете localStorage игра работает без долговременного сохранения.

**60 FPS на физическом телефоне не подтверждены.** Сравнительный шестисекундный прогон в SwiftShader дал: desktop 1280×720 — 10 → 17 FPS, мобильная эмуляция 393×659 — 11 → 19 FPS (в обоих случаях Auto снижает DPR до 0,67). Это программный рендер, а не Adreno 6xx или iPhone GPU. Снижение разрешения может давать мягкую картинку; для мощного GPU доступны режимы High/Auto. Частоту следует измерить на реальном смартфоне. Эмуляция мобильного размера не заменяет реальный Safari, сенсор и прослушивание звука.

Документация библиотек: `https://threejs.org/docs/`, `https://playwright.dev/docs/browsers`. MIT-лицензия локальной three.js включена в `vendor/three/LICENSE`.
