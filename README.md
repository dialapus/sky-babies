# Небесные малыши (Sky Babies)

Браузерный 3D-раннер на three.js: малышка бежит по облачной дороге небесного мира и обходит ямы, чтобы не упасть на Землю раньше времени.

- Основная версия (рой ChatGPT, three.js 0.160.0 из CDN): https://dialapus.github.io/sky-babies/
- Версия в стиле Subway Surfers (GPT-6 Pro, локальная three.js 0.160.1): https://dialapus.github.io/sky-babies/sky-babies-run/
- Отдельная игра — пиксельный платформер «SKYLARK: The Lantern Trail» (рой ChatGPT: 2 раунда по режиссёр + 8 частей, арт на pxl, оригинальные ассеты, 3 уровня; атмосферный свет и полноэкранная мобильная раскладка): https://dialapus.github.io/sky-babies/pixel-platformer/

Управление: ← → / A D — дорожка, ↑ / W / пробел — прыжок, ↓ / S — подкат (во второй версии), на телефоне — свайпы.
Автотест: `?autotest=fall`.

Платформер: ← → / A D — бег, пробел / ↑ / W / Z — прыжок, P / Esc — пауза, на телефоне — экранные кнопки. Автотест: `pixel-platformer/?autotest=1`. Качество света: `?light=high|low|off`.
